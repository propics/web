# Propics website

Next.js 16 App Router site for Propics, compiled with Turbopack.

## Scripts

- `npm run dev` — `next dev --turbopack` on port 5173
- `npm run build` — `next build --turbopack`
- `npm start` — `next start`
- `npm run lint` — ESLint
- `npm test` — production build, then route and metadata checks

Copy `.env.example` to `.env.local` for local notify/dev-mode settings. See `LOCAL_SETUP.md` for Gmail / Apps Script wiring.
